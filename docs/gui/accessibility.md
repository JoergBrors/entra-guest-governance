# Accessibility

Stand: 2026-08-29

Umgesetzt:

- Semantische `nav`, `header` und `main` Bereiche in `AppLayout`.
- ARIA Labels fuer Navigation, Suche, Theme-Auswahl und Theme-Preview.
- Status-Badges enthalten Text und verlassen sich nicht nur auf Farbe.
- Fokuszustand fuer Navigation ist sichtbar.
- Theme Tokens steuern Farben zentral.

Noch offen:

- Automatisierte Accessibility-Checks mit axe oder vergleichbarem Tool: `integration pending`.
